Добро пожаловать на сайт

Этот сайт посвящен проекту, который предоставляет инновационные IT-сервисы. Узнайте о его целях, команде разработки, текущих результатах и ознакомьтесь с полезными материалами для лучшего понимания возможностей.

Цель проекта

Целью проекта является увеличение продуктивности студентов и сотрудников, обеспечив более удобное и эффективное взаимодействие с сервисами Московского политеха за счёт их разработки, внедрения и модернизации.
В рамках проекта мы рассматриваем 3 подпроекта:
• Личный кабинет Московского политеха;
• Мобильное приложение личного кабинета;
• Сервис визуализации данных контакт-центра

Московского политеха на базе Grafana. В каждом проекте были поставлены свои задачи. В рамках личного кабинета мы должны, во-первых, сформировать команду для разработки новых микросервисов, во-вторых, ознакомится с существующими механизмами ЛК.

О нашей команде

Формирование команды для разработки Личного кабинета начинается с подбора ключевых специалистов, которые смогут эффективно работать над проектом, опираясь на текущие задачи и требования. На данном этапе технический руководитель активно участвует в процессе отбора, анализируя нужды проекта и определяя, какие именно компетенции и опыт необходимы для успешной реализации функционала. Главной целью является собрать команду, которая будет включать экспертов по различным направлениям: разработчиков на C# и Python для работы с микросервисной архитектурой, инженеров по базам данных, специалистов по фронтенд-разработке, а также тестировщиков и специалистов по DevOps для обеспечения стабильности и автоматизации процессов разработки и развертывания. В дальнейшем технический руководитель будет уточнять и корректировать состав команды в зависимости от эволюции проекта и изменения требований к функционалу Личного кабинета. Приоритет будет отдаваться специалистам с опытом работы в микросервисных архитектурах и навыками интеграции различных сервисов и API. Такой подход позволит не только гибко реагировать на потребности проекта, но и эффективно распределять задачи между членами команды, что сократит сроки разработки и повысит качество конечного продукта.
