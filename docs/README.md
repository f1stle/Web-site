🔍 Тема
Разработка ИТ-сервисов для Цифрового университета в рамках проекта Московского Политеха и создание информационного веб-сайта на основе выполненного проекта.

🎯 Цель работы
Изучить и реализовать цифровые решения для улучшения образовательной среды.

Разработать ИТ-сервисы: личный кабинет, мобильные приложения и визуализацию данных.

Повысить удобство взаимодействия студентов и сотрудников с инфраструктурой университета.

Создать простой веб-сайт, визуализирующий информацию о проекте.

📚 Изученный материал
Проект включает три ключевых направления:

Личный кабинет — разработка микросервисов для онлайн-доступа к функционалу Политеха.

Мобильное приложение — адаптация ЛК под Android и iOS, включая справочник, новости и карты.

Визуализация данных — внедрение сервиса Grafana для мониторинга показателей колл-центра.

Также были изучены и учтены системные требования, особенности UI/UX-дизайна (в Figma), и принципы микросервисной архитектуры.

💡 Мотивация
Проект направлен на цифровую трансформацию университета, улучшение пользовательского опыта и практическую подготовку студентов в рамках реальных задач по разработке.
Также дополнительной мотивацией стало желание систематизировать полученные знания и представить их в виде простого HTML-сайта.

🌐 Описание разработанных решений
🔧 Технологии:
Frontend: Figma (прототипы), Android, iOS

Backend: C#, Python, MySQL

Мониторинг: Grafana

DevOps: Развёртывание и настройка на сервере

HTML5 + CSS3 — для сайта-отчёта о проекте

📦 Основные компоненты проекта:
1. Личный кабинет
Сформирована команда разработчиков и DevOps-инженеров.

Проект реализуется на микросервисной архитектуре.

Происходит интеграция различных API и сервисов.

2. Мобильные приложения
Созданы макеты интерфейсов в Figma (Android и iOS).

Включены разделы: Телефонный справочник, Новости, Карты, Уведомления.

Команды iOS и Android работают параллельно, соблюдая единый стиль и функционал.

3. Визуализация данных (Grafana)
Развёрнут тестовый сервер Grafana.

Реализованы панели с аналитикой: время ожидания, длительность вызовов, средние значения.

Визуализация помогает отслеживать эффективность операторов в реальном времени.

🌍 Разработка информационного веб-сайта
📌 Цель:
Создание простого веб-сайта, визуализирующего структуру проекта, его цели, задачи и достигнутые результаты.

🧾 Заключение
Благодаря участию в проекте был получен практический опыт в разработке ИТ-решений: от формирования команд до реализации прототипов и сервисов. Реализованы ключевые функции Личного кабинета, мобильных приложений и системы мониторинга колл-центра.
